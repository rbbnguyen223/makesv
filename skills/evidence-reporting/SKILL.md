# Evidence Reporting

Every important finding must include timestamp, source file/log, exact value/address/text when applicable, conclusion and confidence category.

Use:
[CONFIRMED]
[DERIVED]
[UNKNOWN]
[NEXT]

Avoid unsupported "maybe", "probably" and "could be" statements.

When updating Markdown:
1. Read the current Markdown.
2. Locate the actual current section.
3. Make the smallest necessary edit.
4. Preserve unrelated content.
5. Verify the resulting Markdown.
